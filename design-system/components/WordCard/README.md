# WordCard

One recorded Chak word: a play button, the romanised headword, IPA, meaning and credits. The core unit of the archive section.

- Provide: `roman`, `gloss`; optional `ipa` (no slashes), `script` (the 2016 Chak script form, as an image until a font exists), `category`, `speaker`, `credit`, `src` (audio URL).
- Always credit the speaker when they have agreed to be named. Never invent IPA: leave it out until it is verified.
- Audio must be served from the site itself (copy the Commons .mp3 with its licence); the card never autoplays.
- The headword carries `lang="ckh-Latn"` (Chak, Latin script) for screen readers.
