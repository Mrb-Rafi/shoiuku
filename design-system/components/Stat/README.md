# Stat

A big Space Mono number over an orange rule, with a short label. Used only in the impact strip.

- Provide: `value` (string, as displayed), `label`; optional `unit` and `approx` (adds "~" for field estimates such as "~200 min").
- Only real, sourced figures. Never round up to look bigger; keep the "~" where the source says "about".
- Lay out 3 to 6 in a grid; inside `.su-band` they turn cream and yellow.
