# SectionHeader

Eyebrow, uppercase Space Mono title and an optional lead paragraph that open every page section.

- Provide: `title`; optional `eyebrow` (2 to 3 words), `intro` (one or two sentences), `align="center"`.
- `hook` draws the logo's hook stroke under the title.
- `numeral` adds the guideline's oversized faded chapter number behind the title. Use it only where sections are a real sequence (the journey, the roadmap), never as decoration on every section.
- One `h1` per page (`as="h1"` in the hero); sections use the default `h2`.
