# Timeline

The project's journey as a vertical list of steps. Dots encode the kind of step: hollow (step), orange (milestone), yellow (discovery), rust ring (blocker).

- Provide: `items`, each with `title` and optional `when`, `text`, `kind`.
- Keep it in true order. `when` can be a date or a phase word ("Fieldwork") when exact dates are unknown.
- One or two sentences per step; link out for detail.
