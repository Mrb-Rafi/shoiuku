# PressCard

A press mention. `kind="article"` is a linked card; `kind="reel"` puts a 9:16 media frame beside the text for the Nutshell Today reel.

- Provide: `outlet`, `headline`, `href`; optional `author`, `date`, `quote` (paraphrase unless you have permission), `media` (the reel's iframe or a poster image).
- Always keep the outlet name and a link to the original. Opens in a new tab.
- The reel frame keeps a poster or text inside it, so it never looks empty if a browser blocks the Facebook embed.
