# Button

Pill-shaped action set in Space Mono capitals. Use **primary** (orange fill, `on-orange` label) once per view for the action the section exists for. **secondary** is an `ink` outline for the second choice. **quiet** is an underlined `orange-text` link for minor actions.

- Provide: `children` (the label), and `href` to render a link instead of a button.
- Labels are verbs, 1 to 4 words: "Listen to Chak", "Help build the keyboard". No exclamation marks.
- Inside a `.su-band` (brown) section, secondary turns cream automatically.
- Do not put a primary button on an orange or yellow fill.
